# Lexora v0.9.0

这一版聚焦于论文阅读时的响应速度、来源检索和浮窗交互稳定性。

## 新增与优化

- 划词后优先返回一句话与简要解释；深入解读和文献检索在后台并行准备。
- AI 主题优先检索 arXiv，医学主题优先检索 PubMed；必要时补充 Crossref，并在深入内容中展示可点击的来源标注。
- 支持网页正文和输入框内划词，能够识别术语、句子与多关键词选择。
- 支持浮窗拖动、固定、关闭；固定窗口后仍可继续划词解读。
- 优化失焦自动收起、扩展重新加载后的稳定性，以及设置页的 DeepSeek 与语音配置体验。
- 可选择本地中英文语音朗读。

## 使用边界

Lexora 是用于专业术语阅读与学习的浏览器扩展。医学内容不构成诊断、治疗或用药建议。
